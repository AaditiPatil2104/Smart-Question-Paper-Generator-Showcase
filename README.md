# Smart Question Paper Generator

### AI-Assisted Examination Paper Preparation System

## About the Project

The Smart Question Paper Generator is an MCA academic project designed to simplify the examination paper preparation process. It provides a web-based interface for managing question banks and generating structured question papers.

The project includes a Teacher Module, a Coordinator Module, and a Bot Assistant.

## Key Features

- Question Bank Management
- Subject and Syllabus Management
- AI-Assisted Question Generation
- Automatic Question Paper Generation
- PDF Question Paper Output
- Previous Paper Management
- Coordinator Module
- Bot Assistant for Application Guidance

## Technology Stack

- **Programming Language:** Python
- **Backend Framework:** Flask
- **Database:** SQLite
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **AI Integration:** Google Gemini API
- **PDF Generation:** ReportLab
